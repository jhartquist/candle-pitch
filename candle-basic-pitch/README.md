# candle-basic-pitch

Basic Pitch polyphonic note transcription in [candle](https://github.com/huggingface/candle).

A port of [Spotify's Basic Pitch](https://github.com/spotify/basic-pitch) (Bittner et al., ICASSP 2022), validated against the reference TensorFlow implementation for numerical parity.
